# 怎么查当前项目的交付特例

按 TAPD 工作区和本机映射定位到实际规则根，读取该项目的 AGENTS.md、CLAUDE.md、项目 skill 及交接记录。多个仓的源分支、目标、审批人、构建参数可各不相同；不拿另一个项目的最新成功记录当默认值。

| 要决定的动作 | 去哪里确认 |
|---|---|
| 切工作树、组织提交 | 原工单及工作树映射；项目对单号、标题和产物的提交约定 |
| 提 MR 或直推 | 项目规定的目标分支、标题模板、是否需 MR、前后端各自审批人；再核对 QE 当次返回 |
| 发布一组服务 | 各仓→实例/folder/job 的映射、模块参数、依赖顺序、哪些 job 只构建、哪个才部署 |
| 转测 | 当前环境发布证据、项目验收门禁、测试主体和需要一起回写的服务 |

迁移工作站时从原有私有项目卡恢复这些非通用规则；本表没有项目名单不代表项目没有特例。如果仍有两个合理目标，只问影响这次写操作的那一项。项目信息放本地项目卡，账号和令牌走批准的凭据渠道。
