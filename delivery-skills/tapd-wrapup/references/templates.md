# 评论模板

## 需求转测说明

```html
<p><b>【转测说明】</b></p>
<p><b>流转说明</b>：{逐级流转到转测；未真实召开的评审写「按工作流补流转，以实际为准」}</p>
<p><b>转测内容</b>：{一两句话说清这次改了什么，用业务语言}</p>
<p><b>分支与提交</b>：{仓库 → 分支 → MR 编号/合并状态}</p>
<p><b>发版</b>：{Jenkins job #构建号 / 安装包版本；未发版要写明}</p>
<p><b>前置条件</b>：{测试前必须满足的：账号、数据、配置、MR 合入}</p>
<p><b>测试要点</b>：</p>
<p>1. {正向场景}<br/>2. {边界/非法输入及期望提示}<br/>3. {保存后回显}<br/>4. {关联页面显示}<br/>5. {不应受影响的回归点}<br/>6. {联调点}</p>
```

## 缺陷转测（修复已发版）

```html
<p><strong>【已修复，可转测】</strong></p>
<p><strong>【问题原因】</strong><br/>{一到三句}</p>
<p><strong>【修复逻辑】</strong><br/>{改了什么}</p>
<p><strong>【分支与发版】</strong><br/>{分支 / commit / MR / 构建号}</p>
<p><strong>【测试注意】</strong><br/>{复测步骤、测试数据、需要回归的点}</p>
```

## 转测提醒（可转测但有前提）

```html
<p><strong>【转测提醒】</strong>{测试前需要注意的一件事，例如：需用 XX 账号 / 需先执行 XX 配置 / 后端 XX 接口同步改动已发版}</p>
```
