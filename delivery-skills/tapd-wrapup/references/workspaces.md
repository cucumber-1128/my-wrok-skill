# 对这张单，哪些规则适用？

| 需要核对的事实 | 依据 |
|---|---|
| Workspace、实体类型和 ID | 原始链接、TAPD MCP 读回的对象；平台项目 ID 不替代 TAPD workspace |
| 评论作者、当前处理人、测试/后端接手人 | 当前会话已核实的 TAPD 身份，原单字段及项目角色映射 |
| 可转状态、实际允许的下一步、必填字段 | 项目工作流与该 workspace、该实体的当前状态图/允许路径；平台允许跳转并不证明评审开过 |
| 分类、任务命名和花费归属 | 分类与命名核对项目规则和同迭代任务。花费只挂 task，核实实际任务 ID；旧表的 bug 直挂不再执行 |
| 能否转测 | 各服务实际合入与部署的版本、验证证据、未完成依赖；不是另一个分支或旧构建的状态 |

常用映射写在本机私有项目卡，记录来源和适用范围。不要把真实人员、租户工单、测试账号或凭据提交到公开技能。
